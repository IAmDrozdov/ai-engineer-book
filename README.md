# Чеклист AI-инженера

Самоучитель из 17 глав по мотивам поста «Чеклист AI-инженера» (@fastnewsdev). Состояние на
осень 2026 года.

Открывать: `index.html` (оглавление и карта) или любую главу `NN-*/index.html`. Всё работает
с диска, без сети: шрифты, mermaid и подсветка кода лежат в `assets/`. Отметки в чеклистах
навыков и прогресс чтения хранятся в браузере (localStorage) и видны в оглавлении.

## Что где

| Путь | Что это |
|---|---|
| `index.html` | Обложка, карта книги, оглавление с прогрессом, соответствие пунктов поста главам |
| `NN-<тема>/index.html` | Глава |
| `NN-<тема>/research/` | Исследовательские заметки (spec, practice, field, gaps), план, отчёты рецензентов, журнал правок, отчёт sepia — весь след источников |
| `assets/` | `book.css`, `book.js`, `manifest.js` (оглавление и порядок глав), шрифты, mermaid, highlight.js |
| `tools/qa.mjs` | Проверка страницы в headless Chrome: ошибки схем, наложения подписей, битые ссылки, скриншоты рисунков |
| `tools/shot.mjs` | Скриншот любой страницы |
| `tools/prose.py` | Текст главы без разметки, по абзацу на строку, для grep |
| `_meta/AUTHORING.md` | Инструкция автора главы: голос, правила текста, компоненты, рисунки |
| `_meta/demo/index.html` | Демо всех компонентов вёрстки |
| `_meta/consistency/` | Отчёты сверки фактов между главами |

## Как проверить главу после правки

```bash
node tools/qa.mjs 05-mcp --shots        # отчёт + скриншоты рисунков в _qa/05-mcp/
node tools/qa.mjs 05-mcp --dark --shots # то же в тёмной теме
```

`ISSUES none` — страница чистая. Скриншоты стоит посмотреть глазами.

## Как это делалось

Для каждой главы три исследователя (первичные источники, инженерная практика, форумы и отчёты
практиков) и критик полноты собрали заметки по живому вебу; автор написал главу по заметкам;
четыре рецензента (факты, код и рисунки, полнота, читатель) проверили её; автор внёс правки;
прошёл проход sepia по тексту; выпускающий проверил вёрстку и каждый рисунок; приёмщик выборочно
перепроверил 20–30 фактов по первоисточникам. Затем сверка фактов между главами.
