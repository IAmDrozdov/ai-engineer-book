### Discourse pass (§1–3)

- **QUD по разделам:** что уходит по проводу → сколько на самом деле типов событий (проверка 16/19/31/36)
  → собрать обе стороны руками → чем кончается прогон (пользователь закрыл вкладку) → правило «не отвечать»
  → трасса HITL, потом механизм → миф про «двустороннюю синхронизацию» → жалоба с r/LangGraph про параллельные
  ветки → документация против спецификации о транспортах → хронология 1.0 → интерфейс → соседние протоколы
  (Claude Code в Zed) → критика → рекомендация. Анкеты «что → зачем → как → вывод» нет.
- **Ходы-сравнения и проверки:** есть и те и другие. Концептуальная страница против нормативного текста,
  AG-UI против Vercel, ChatKit и useStream, опровергнутая атрибуция MCP Apps, мост LangGraph, который по
  умолчанию нарушает MUST.
- **Тест первых предложений:** конспекта не получается, много фраз, непонятных без контекста («Механика
  простая.», «Путаница старая.», «Здесь две оговорки.», «Причина в совместимости.»). Проходит.
- **Середина:** в HITL, состоянии и сабагентах лежат неожиданные вещи: нарушение MUST у LangGraph, повторное
  выполнение у ADK на двух репликах, небезопасный повтор `resume[]` в собственном наброске главы. Проходит.
- **Позиции на странице:** абзацы от 3 до 130 слов, есть абзацы из одного предложения, цитаты стоят и внутри
  абзацев, и в конце. `<mark>` сосредоточен в четырёх–пяти местах. Проходит.
