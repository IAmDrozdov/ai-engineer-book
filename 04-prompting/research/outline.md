# Глава 04 — план

Шапка. Lead: одна строка про лимит слов в системном промпте Claude Code (16.04.2026) → минус 3% на широком eval → откат 20.04. Промпт агента — код в каждом запросе, у него бывают регрессии.

## Разделы (с чего начинается / главное)

1. `anatomy` «Что на самом деле уходит в модель». Начало: дословные первые строки промпта Claude Code под Opus 5.5 (снимок 22.09.2026): таблица effort раньше роли. Главное: где живёт инструкция — system/developer, tools, messages, mid-conversation system (с 15.07.2026), turn-scoped `clear_at` (бета); у кого какой авторитет; `<pasted_content>`; недоверенный текст в system нельзя (→ гл. 16). Рис.: SVG-анатомия запроса; stateDiagram жизни turn-scoped сообщения.
2. `altitude` «Высота инструкции». Начало: противоречивый промпт из гайда GPT-5 (согласие пациента vs «ставь первый слот без звонка»), модель тратит reasoning на примирение. Главное: цитата Anthropic про две крайности; правило «could the model already know this?»; причина рядом с запретом (TTS/многоточия); примеры сильнее инструкций; расхождение вендоров по few-shot (Google always / Anthropic 3–5 + «примеры замораживают старую модель» / OpenAI zero-shot first); XML vs Markdown; данные до вопроса. Рис.: versus из трёх колонок (низко / нужная высота / высоко).
3. `overtrigger` «Почему крик перестал работать». Начало: лестница версий JetBrains benjamin-plus (v1 обвал награды → v2 +52% выхода → … → v5 LEAN). Главное: «quality guards are not free»; цитата Anthropic про Opus 4.5/4.6; таблица pressure language из prompt-audit; буквальность (Sonnet 5.5 и «minimize tool calls»; абзац против ревьюер-сабагентов −⅓ стоимости); спор: CAPS не запрещён (Gemini MUST, «Emphasis is not banned»); практикум: grep по CLAUDE.md, `/claude-api prompt-audit`. Рис.: pipeline версий; hbar итогов v6.
4. `params` «Рычаги API переехали в текст». Начало: текст ошибки 400 про `tool_choice`. Главное: prefill, forced tool_choice, temperature, budget_tokens, disabled thinking → 400; замены; effort как главный регулятор, имена effort не совпадают между моделями; CoT vs reasoning-модели (OpenAI: не просить step by step; Anthropic: «think thoroughly» лучше плана; Opus 5.5: убрать «think carefully»; Sonnet 5.5: одна фраза для JSON; Gemini: thinking_level). Рис.: flowchart «параметр → 400 → замена». Таблица дефолтов effort.
5. `per-model` «Гайды под конкретные модели». Начало: гайд GPT-5 от августа 2025 описывает модель, снапшот которой выключат 11.12.2026. Главное: как читать per-model страницы; что в них сейчас (упр. харнессом: elapsed time, completion check, mid-turn input); GPT-6 Astra и AGENTS.md; спор о стиле: список запрещённых фраз OpenAI vs позитивная формулировка Anthropic. Хронология полугодия.
6. `prompts-as-code` «Промпт как код». Начало: OpenAI «For new work, don't create reusable prompt objects» (депрекация 03.06.2026). Главное: разбор постмортема (узкий eval пропустил строку, абляция по строкам нашла, гейтинг по модели, soak, постепенная выкатка); где строка жила до выкатки (только для сотрудников, Breunig); раскладка в репо: промпт-модуль с типизированными параметрами + регрессионный тест (набросок); Hamel: сначала error analysis, бинарные метки. Evals → гл. 17. Рис.: pipeline выкатки изменения промпта.
7. `cache-layout` «Раскладка под кеш». Начало: Ask HN, $37 901,73 за Bedrock. Главное: префикс tools → system → messages; что его ломает (время в system, недетерминированный JSON схем, смена effort, правка истории); минимум кешируемого префикса по моделям; `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__`; cache diagnostics GA 23.09.2026. Экономика кеша → гл. 2. Рис.: SVG префикса с границей; sequence диагностики; hbar минимумов.
8. `debugging` «Отладка: транскрипт, абляция, вопрос „почему“». Начало: инстинкт спросить модель «почему ты так сделал» — на Opus 5.5 можно получить отказ `reasoning_extraction`, оплачиваемый с 24.09.2026. Главное: чтение сырых транскриптов и error analysis; попросить процитировать инструкцию (промпт GPT-6); самообъяснение — гипотеза (25%/39%); «Asking the model whether it needs an instruction is not a measurement»; остановки в автономном режиме чинить харнессом; текст харнесса после tool_result как инъекция. Рис.: flowchart симптом → первый инструмент.
9. `vendor-tools` «Оптимизаторы от вендоров: что осталось к осени». Начало: 17.08.2026 выключены `/v1/experimental/improve_prompt` и компания. Главное: таблица статусов; OpenAI Optimize (интерактивный и на датасете: ≥3 строк, грейдеры, output_feedback; «может стать хуже»); metaprompt-ноутбук без prefill; prompt-audit как рубрика; метапромптинг в смысле вендоров (diagnose → revise) vs meta-prompting Suzgun & Kalai 2024.
10. `dspy-gepa` «DSPy, GEPA и TextGrad». Начало: HN-комментарий TheTaytay про неизвлекаемые промпты. Главное: сигнатуры и компиляция; MIPROv2 в трёх фазах; GEPA: рефлексия по трассам + Парето-фронт; метрика с feedback; числа v2 и где GEPA проиграл; TextGrad (Nature, заброшен); Anderson «agents are not modular programs»; DSPy 3.3 Flex, 3.4. Вердикт: когда брать. Рис.: flowchart цикла GEPA; hbar GPT-4.1 Mini; hbar Qwen3-8B с роллаутами.
11. `tool-descriptions` «Описания инструментов как объект оптимизации». Начало: «the most common failure is under-description». Главное: контракт внутрь, примеры и управление поведением наружу; системный промпт не называет тулы; транскрипты → Claude Code; GEPA MCP-адаптер; Ronacher и strict. Подробно → гл. 3.
12. `study` «Чужие системные промпты как учебник». Начало: первая строка базового промпта Codex CLI из открытого репо. Главное: официальные корпуса (Anthropic claude.ai по моделям — не для API; Codex; Piebald для Claude Code, 301 версия); утечки как второй эшелон; что искать (внутренняя и внешняя версия Output Efficiency в Claude Code: CAPS для внешних); вечернее упражнение: diff промптов двух версий. Рис.: flowchart сборки промпта Claude Code.

## Проверка плана по §3
- Анкета: разделы не идут «что → зачем → как → плюсы/минусы». Порядок: артефакт → принцип → сбой → миграция → гайды → процесс → кеш → отладка → автоматизация → частный случай → чужие промпты. Раздел 3 начинается со сбоя, раздел 7 — с инцидента, раздел 10 — с жалобы.
- Первые предложения разделов: цитата промпта; противоречивый промпт; лестница версий; текст ошибки; дата гайда; цитата OpenAI; счёт за Bedrock; инстинкт спросить «почему»; дата выключения API; комментарий HN; строка из prompt-audit; строка Codex. Конспекта не получается.
