### Discourse pass (§1–3)

- **QUD по разделам:** какие бывают классы (по payload) → как A2UI устроен изнутри → почему каталог не защитил
  (CVE) → как формат менялся трижды → MCP Apps → Python за вечер → куда ушёл OpenAI → свой фронтенд → паттерны
  → что показывают замеры → кто внедрил → как выбрать. Не анкета «что → зачем → как → вывод»: ядро главы —
  проверка обещаний протоколов, и почти каждый раздел содержит опровержение (кнопка с `javascript:`, потерянный
  `root`, три разных `catalogId`, `actionResponse` в документации, ошибки в примере спецификации, неверный
  README CopilotKit). Финальный раздел-выбор требует AUTHORING §2, это не рефлексивный хвост.
- **Тест первых предложений:** конспекта не получается. Много предложений, непонятных без контекста
  («Ничего сетевого.», «Вторая беда тише.», «Надёжнее названные внедрения.», «Выигрыш не только в перерисовках.»,
  «Условия здесь важнее чисел.»). Проходит.
- **Середина:** CVE и нарушение собственных правил эволюции (#1469) стоят в середине, разбор `actionResponse`
  и три ошибки в примере спецификации — там же. Есть сравнение (Express против OpenUI Lang), проверка расхожего
  утверждения (json-render «рендерер A2UI», Open-JSON-UI, README CopilotKit про URL в iframe). Проходит.
- **Позиции на странице:** длина абзацев от 13 до 158 слов, есть абзацы из одного-двух коротких предложений.
  Цитаты стоят и в начале, и в середине, и в конце абзацев. Тройки — настоящие (три класса, три сообщения,
  три ошибки, три способа совмещения). Проходит, кроме переполненных абзацев из #9.
