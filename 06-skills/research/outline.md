Состояние на 30 сентября 2026. Первичка перепроверена по docs Claude Code (skills.md, changelog до v2.1.285),
agentskills.io/specification, SEP-2640 (ext-skills), Skills API guide, best practices; Vercel-блог перечитан.

## Вводка
Vercel положил документацию Next.js 16 в скилл: в 56% прогонов агент его не открыл, результат 53% — как без
документации вообще. Тот же текст индексом на 8 КБ в AGENTS.md дал 100%. Глава о том, почему папка с markdown
ведёт себя так, и где она всё-таки выигрывает.

## Разделы

1. `anatomy` «Папка с одним обязательным файлом». Начало: скилл summarize-changes целиком (VERBATIM из docs CC).
   Главное: скилл — не API, а файлы, которые модель читает своими инструментами; поэтому нужен shell/FS.
   6 полей спеки, ограничения name, отличия валидации Anthropic (claude/anthropic, XML), CC-поля сверху.
2. `disclosure` «Три уровня загрузки и их цена». Начало: changelog v2.1.234 — claude-api скилл 200k+ → 25k.
   Главное: уровень 1 платится всегда и на каждом ходе, 2 — один раз и живёт до конца, 3 — по чтению;
   скрипт стоит только stdout. Цифры ~100/<5k/0, OpenClaw-формула 24 ток. Кеш промпта.
3. `triggering` «Почему скилл не срабатывает». Начало: rane на HN, bash-скилл не вызвался (окт. 2025) +
   признание skill-creator «undertrigger». Главное: классификатора нет, решает модель по листингу; листинг
   режется бюджетом 1% окна, 1 536 символов; молчаливые провалы фронтматтера; skillcrossroads 69% (эвристика);
   управление видимостью: disable-model-invocation, user-invocable, skillOverrides, paths; /context, /doctor,
   /skill-doctor. Где провал: самый длинный раздел, диагностическое дерево.
4. `lifecycle` «Что происходит после вызова». Начало: «скилл перестал работать посреди сессии» из docs.
   Главное: одно сообщение, не перечитывается, allowed-tools живёт один ход; компакция 5k/25k; `!`-инъекция
   до модели, падение команды отменяет вызов; context: fork — сабагент без истории, фон с v2.1.218, /rewind не
   откатывает.
5. `api` «Скиллы вне терминала». Начало: запрос Messages API с container.skills (VERBATIM).
   Главное: три версии code execution, без beta; /skills/{name}/, нет сети и pip; 20 на запрос; workspace-scope
   как ловушка мультитенанта; не ZDR; кеш ломается при смене списка; pause_turn цикл; file_id; миграция с беты;
   Managed Agents (500, repo без ревью); Agent SDK (skills=..., не граница безопасности).
6. `standard` «Открытый стандарт и его швы». Начало: одноимённый deploy в ~/.claude и в репо — CC берёт личный,
   Gemini CLI — проектный. Главное: переносимы name+description+тело; матрица клиентов; таймлайн; управление
   (нет фонда, Anthropic ревьюит логотипы; Agent Plugins с TSC без Anthropic).
7. `versus` «Скилл, MCP, сабагент, команда, CLAUDE.md». Начало: HN «skills have largely replaced MCP» (фев. 2026)
   против сентября 2026, когда MCP получил официальное расширение для доставки скиллов. Главное: что верно в
   токен-аргументе Уиллисона, что нет; SEP-2640 (skills/list, digests, content-bound approval); Vercel-график;
   решение «куда класть знание».
8. `authoring` «Как написать скилл, который помогает». Начало: SkillsBench — самописные скиллы 0, курируемые
   +16,6 п.п., SWE +4,5. Главное: description (третье лицо, что+когда, «напористо», near-miss негативы, 20
   запросов × 3), краткость, степени свободы, скрипты для агента, один уровень ссылок, gotchas, модели разного
   размера, Claude A/B, evals: skill-creator, claude plugin eval; 91,8% дефектов в 138K файлов. Набросок
   скилла для Python-бэкенда.
9. `distribution` «Как скиллы доезжают до людей». Начало: sync claude.ai → ~/.claude/skills/synced (v2.1.275).
   Главное: git, плагины и маркетплейсы, npx skills / skills.sh, орг-провижининг (с 18.12.2025), publish-to-org,
   сканирование, Skills API, Agent Plugins; синхронизированные скиллы урезаны в правах.
10. `security` «Скилл — это код, который выполняет модель». Начало: Jason Meller и странная зависимость
    openclaw-core (1Password, 02.02.2026). Главное: «документация — это установщик»; Snyk (правильное чтение
    36%), сканеры не сходятся (0,04% vs 4,4%; 0,69%), AIR PoC с внешним доменом (не «26 тыс. жертв»),
    сквоттинг неймспейсов; в CC: allowed-tools без workspace trust, `!` до модели, disableSkillShellExecution;
    Enterprise-сканирование с 02.10.2026; чеклист ревью. Подробно — глава 16.

- Анкета «что → зачем → как → плюсы/минусы → вывод»: нет; разделы идут от механизма к сбоям, сравнение стоит
  после механики, в середине (7) есть проверка расхожего утверждения, которое оказывается неверным.
- Первые предложения: начинаются с артефактов (код, строка changelog, коммент HN, JSON, число из бенчмарка,
  имя исследователя) — конспекта главы из них не складывается.
- Где провал: разделы 3, 7, 8, 10 — в них основной объём; 2, 6, 9 короче.
- Не использую: rtk-цифры (не про скиллы), benjamin-plus и deslop-GPT (не перепроверены), OpenClaw «346K
  stars», skills.sh «1 508 673» (единица не подписана).
