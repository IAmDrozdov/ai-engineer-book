## Разделы

1. `authority` — «Полномочия лежат там, где лежит ключ». Начало: эксперимент LAB-042/LAB-043 с
   n8n. Главное: четыре места в любой интеграции (модель предлагает, тул-слой исполняет, хранилище
   держит секрет, внешний API проверяет своё); три вопроса — от чьего имени, где секрет, кто
   разрешает конкретный вызов. AIMS: «LLM MUST NOT have access to an agent's credentials».
   Рис.: flowchart пути tool call с местами проверки.
2. `whose-identity` — «От чьего имени». Начало: разбор настоящего OBO-токена Auth0 с вложенным `act`.
   Главное: своя личность (client credentials), делегирование (code + PKCE), OBO через RFC 8693;
   делегирование против имперсонации; три диалекта OBO (Entra jwt-bearer + fmi_path, AgentCore
   8693 или 7523, Auth0 8693 без refresh). Выбор. Набросок обмена на httpx.
   Рис.: sequence OBO; versus трёх диалектов.
3. `mcp-oauth` — «MCP-сервер как resource server». Начало: `curl` в Linear MCP и настоящий 401.
   Главное: PRM → метаданные AS → PKCE + `resource` + записанный issuer → `iss` → токен в каждом
   запросе; аудитория MUST, passthrough MUST NOT; step-up с объединением scope; что поменяла
   2026-07-28 (нет сессий, `Mcp-Method`/`Mcp-Name`). Python: MCPServer + TokenVerifier.
   Claude Code: `/mcp`, `headers` с `${VAR}`, `headersHelper`, закрепление `oauth.scopes`.
   Рис.: sequence полного потока.
4. `registration` — «Кто такой клиент: CIMD вместо DCR». Начало: у клиента и сервера нет общего
   прошлого. Главное: CIMD-документ, почему DCR объявили устаревшим (операционные причины, а не
   confused deputy), порядок регистрации, привязка к issuer, `application_type`; что в поле:
   замер 12 серверов, баги клиентов по changelog Claude Code.
   Рис.: flowchart порядка регистрации; hbar замера 12 серверов.
5. `enterprise` — «Согласие даёт IdP». Начало: EMA Stable 2026-06-18, «zero-touch OAuth».
   Главное: два запроса на проводе (token exchange → ID-JAG → jwt-bearer), ID-JAG ≠ identity
   chaining, отзыв в IdP; критика: только OAuth, «кто», а не «что».
   Рис.: sequence EMA.
6. `vault` — «Токен вне контекста и мастер-ключ хранилища». Начало: Cyera 2026-08-13, ключ
   Composio вернул живые токены Gmail/GitHub. Главное: хостовые API не ведут OAuth за тебя;
   схема хранилища и пути утечки; платформы и выбор; дыры прокси (refresh в теле ответа);
   что делают практики. Рис.: flowchart хранилища с путями утечки.
7. `per-call` — «Токен выдан пять минут назад». Начало: цитата Arcade про EMA. Главное: время
   подключения против времени вызова; AuthZEN 1.0 как PEP→PDP; грубость scope; transaction
   tokens; аудит. Рис.: sequence со временем, где OAuth пропускает, а PDP запрещает.
8. `approval` — «Подтверждение, которое что-то значит». Начало: хук PreToolUse, «да» пользователя
   и обход. Главное: AIMS MUST NOT локальное «ок»; elicitation через MRTR (form/URL, секреты
   только URL, `requestState`); CIBA + RAR; фишинг согласия (RFC 10027). Таблица выбора.
   Рис.: sequence URL-mode через MRTR; sequence CIBA.
9. `gateway` — «Шлюз, который меняет токены». Начало: конфиг Kong, который по умолчанию срезает
   токен. Главное: passthrough против exchange; agentgateway, Docker, СберТех; шлюз против тонкой
   обёртки — выбор с условием. Рис.: flowchart двух путей.
10. `database` — «Агент у базы данных». Начало: текст тикета из инцидента Supabase. Главное: это
    промпт-инъекция, а не SQL-инъекция; read-only транзакция не граница; роль, RLS и её исключения;
    GUC и `set_config`; параметры из токена (MCP Toolbox); SSRF CVE-2026-14540.
    Рис.: flowchart SQL-тула с параметром из токена.
11. `reliability` — «Повторы, вебхуки, лимиты». Начало: Temporal «Activities may be retried».
    Главное: idempotency key (Stripe де-факто, IETF-черновик истёк), durable execution, Inngest,
    Standard Webhooks, RateLimit. Рис.: sequence повтора с ключом; pipeline приёма вебхука.
12. `agent-identity` — «Своя личность агента». Начало: Storm-3168. Главное: OAuth доказывает
    токен, а не рантайм; SPIFFE/WIMSE, AIMS -00, DPoP/WIF в дорожной карте MCP, Entra Agent ID,
    Auth0 Agent as Principal; лестница зрелости; что изменилось за полгода (timeline); что делать сейчас.
    Рис.: layers лестницы зрелости стандартов.

Итого рисунков: 16 (flowchart 5, sequence 7, versus 1, layers 1, pipeline 1, hbar 1).
