# Глава 11. Память агента — план

Ось главы: у любой памяти три пути — кто и когда пишет (write path), в каком виде и где лежит,
как возвращается в запрос (read path) — плюс как она стареет и забывается. Каждый продукт
разбирается через эти вопросы, а не по шаблону «что это → плюсы → минусы».

Лид: с v2.1.59 (25 февраля 2026) Claude Code сам пишет заметки в `~/.claude/projects/<project>/memory/`,
и первые 200 строк индекса едут в каждую сессию. В июле 2026 Anthropic назвала auto memory заменой
ручного CLAUDE.md, в том же HN-треде люди пишут, что выключили её и стало лучше.

## Разделы

1. `survives` — «Что переживает окно». Начало: автоматический системный промпт memory tool с
   «ASSUME INTERRUPTION». Главное: у модели памяти нет, память — функция харнесса; CoALA:
   working memory ≠ окно (частая ошибка), episodic/semantic/procedural; соответствие файлам
   Claude Code. Границы: RAG (гл. 14), компакция (гл. 2), skills (гл. 6).
2. `claude-code` — «Память, которая уже лежит у тебя на диске». Начало: дерево каталога auto memory.
   CLAUDE.md против auto memory, 200 строк/25KB, topic-файлы по требованию, `modified`, over-limit error,
   сабагенты (`memory: user|project|local`), AGENTS.md с v2.1.277. Хронология версий.
   Полевые жалобы (sothatsit, bushido, fluidcruft) против позиции Anthropic (Thariq, июль 2026)
   и защитника индекса (ArielTM). Выбор: не выключать, а ревизовать; жёсткие правила — в хуки.
3. `memory-tool` — «Memory tool: память исполняет твой код». Начало: запись `tools` в одну строку.
   Последовательность view → view файла → str_replace, форматы tool_result, is_error, шесть команд,
   path traversal, набросок хендлера на Python. Дата 29.09.2025, не 18.08. Пара с context editing и
   компакцией, числа Anthropic (+39%, −84%). Паттерн initializer/progress log — проект на вечер.
4. `managed` — «Хранилище с версиями и сны: Managed Agents». Начало: JSON подключения store к сессии.
   /mnt/memory, версии memver_, content_sha256, read_only, лимиты, redact, заголовок беты.
   Dreams: вход не меняется, выход — новый store; жизненный цикл; инструкции не правят строки.
5. `files` — «Почему все пришли к файлам». Начало: эксперимент Letta (grep по LoCoMo, 74.0 против
   самоотчёта Mem0 68.5, разные харнессы). LongMemEval-V2 (72.5/69.3/48.5, цена — латентность).
   Конвергенция: MemFS, Deep Agents, Codex, Hermes (замороженный снимок, ошибка на переполнении,
   «модель заявила сохранение, которого не было»), OKF, memoryfields. Контраргумент «5 mistakes».
6. `facts-graphs` — «Факты и графы: Mem0 и Zep». Начало: код add() до и после апреля 2026 (события
   только ADD). Одна LLM-вызов, MD5-дедуп, гибридный поиск, граф ушёл в Platform, Supersede/Merge.
   Полевой отчёт: issue #5352 (time-blindness). Graphiti: valid_at/invalid_at против created_at/expired_at,
   инвалидация без удаления. Таблица стратегий противоречий + выбор. Letta V1 blocks как история.
7. `consumer` — «Память в ChatGPT и Claude.ai». Начало: Willison и «HALF MOON BAY». Три поколения
   памяти Claude (поиск по чатам → сводка раз в 24 часа → Topics с 25.08.2026), ChatGPT: improved memory,
   Sources, приоритизация по давности и частоте, удаление в нескольких местах. Уроки для продукта.
8. `write-path` — «Когда писать: горячий путь и фон». Начало: таблица LangChain Deep Agents.
   Четыре разных «сна» (Anthropic, Mem0, Letta, OpenClaw) — нельзя сливать. OpenClaw: только
   консолидация пишет MEMORY.md, детерминированный гейт по origin, хеш перед заменой.
   Codex memories: фоновое извлечение, `disable_on_external_context`.
9. `read-path` — «Как память возвращается в запрос». Начало: формула Generative Agents с α=1, 0,995,
   порог рефлексии 150. Потомки: ChatGPT (давность × частота), Mem0 Decay, OpenClaw (полураспад 30 дней,
   триггеры ≥0,72, две полосы). Предпочтение ≠ факт (PrefEval через OpenClaw): директивы, замещение.
10. `failures` — «Что ломается». Начало: цепочка Unit 42 (поддельные `</conversation>` в суммаризации).
    Отравление (ASI06, AgentPoison, MINJA, origin binding) — коротко, подробности в гл. 16. Устаревание,
    противоречия, рост, фантомные записи, гонки писателей, приватность и удаление.
11. `benchmarks` — «Бенчмарки памяти: что на самом деле измерено». Начало: таблица статьи Mem0, где
    full-context 72.90 выше Mem0 66.88, а +26% — против памяти OpenAI. LoCoMo помещается в окно,
    MemPalace top_k=50, DMR насыщен, LongMemEval и модель-читатель (Mastra 94.87→84.23), Mem0 OSS
    против Platform, Cognee на 20 вопросах. Вопросы к любой цифре вендора.
12. `self-improvement` — «Агент, который учится на ошибках». Начало: ACE, коллапс контекста
    18 282 → 122 токена и точность ниже базовой. Reflexion → Dynamic Cheatsheet → ACE (дельты,
    детерминированное слияние), Voyager (JS-скиллы, самопроверка перед записью), Letta skill learning
    (+15,7 с верификатором). Обучение на исправлениях: тип `feedback`. Без верификатора — деградация.
13. `design` — «Как выбрать архитектуру памяти». Начало: вопрос «что должно пережить сессию и кто за
    это отвечает». Дерево решений, шаги, что сделать за вечер. Моя рекомендация по умолчанию: файлы +
    индекс + агентный поиск, человеческие правила отдельно, фоновую консолидацию — в новую версию.
