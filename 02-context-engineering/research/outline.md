# Глава 02. Контекст-инженерия — план

Состояние на 30 сентября 2026. Сквозная линия: окно — это массив, который харнесс собирает на каждом шаге;
в нём три силы тянут в разные стороны: качество (гниение контекста), деньги (кеш префикса) и место
(компакция, чистка, вынос, изоляция). Глава объясняет механику каждой и где они конфликтуют.

Лид: жалоба #92098 (2026-09-04): автокомпакция вытолкнула «не трогай базу», 2 251 строка удалена.
Модель не «забыла»: этой фразы не было в следующем запросе.

## Разделы

1. `window` — Что лежит в окне до первого вопроса. Начало: иллюстративная сессия Claude Code из
   документации, ~7,85 тыс. токенов до первого промпта. Главное: всё считается (tools → system →
   messages), скрытые 286–675 токенов на tool use, токенизатор Opus 4.7+ (+30%), count_tokens,
   что модель знает о своём бюджете (budget-теги vs task budgets). Рис.: stack-график.
2. `rot` — Окно портится задолго до лимита. Начало: NoLiMa, GPT-4o 99,3 → 69,7 на 32K. Главное:
   attention budget, Lost in the Middle, Chroma (перемешанный стог лучше связного), Du et al.
   (длина вредит даже при идеальном поиске). Поле: HN «не выше 20%», «это очевидно». Рис.: line NoLiMa.
3. `failures` — Отравление, отвлечение, путаница, конфликт. Начало: Gemini играет в Pokémon.
   Главное: четыре режима Бройнига с правильной атрибуцией (GeoEngine, а не BFCL), шесть лекарств.
   Рис.: versus из четырёх клеток.
4. `frameworks` — Write, select, compress, isolate и что устарело. Начало: определение Карпатого.
   Главное: LangChain, Anthropic 2025, Manus; июль 2026 — «новые правила» для Claude 5 (−80% системного
   промпта). Сравнение: примеры 72→90% (ноябрь 2025) против «примеры сужают» (июль 2026). Таблица.
5. `cache` — Кеш префикса. Начало: Claude Code объявляет SEV при падении hit rate; Manus 100:1.
   Главное: запись только на брейкпоинте, окно поиска 20 блоков, ловушка timestamp, цены
   и множители, минимум 512–4 096, что инвалидирует что, невидимые инвалидаторы в Python.
   Рис.: SVG порядок+ловушка, SVG lookback, line накопленной стоимости.
6. `cache-vendors` — OpenAI и Gemini. Начало: «кеш OpenAI бесплатный» верно для 5.5 и неверно для 5.6.
   Главное: две эпохи OpenAI, prompt_cache_key и 15 rpm, ловушка минимальной длины; Gemini implicit/
   explicit, 10% + хранение, 75% — устаревшая цифра. Вкладки OpenAI/Anthropic/Gemini. Рис.: hbar цен.
   Итог-выбор в конце раздела.
7. `cache-miss` — Кто сдвинул префикс. Начало: ответ diagnostics с system_changed на 41 850 токенов.
   Главное: диагностика обоих вендоров, системные сообщения внутри messages, tool_removal, clear_at,
   preserved thinking и 400 для новых аккаунтов. Рис.: flowchart чтения диагностики; versus правки.
8. `claude-code` — Что в Claude Code стоит кеша. Начало: opusplan — каждый вход в plan mode это смена
   модели. Главное: слои, TTL по типу оплаты, /usage и likely cause, область кеша. Рис.: flowchart
   действий и слоёв. Шаги «сделай за вечер».
9. `clearing` — Чистка результатов инструментов. Начало: −84% токенов в 100-ходовом eval.
   Главное: clear_tool_uses параметры и цена для кеша, бюджеты вывода (25K в Claude Code),
   лестница Deep Agents, обратимое сжатие Manus. Рис.: SVG до/после, pipeline лестницы.
10. `compaction` — Компакция: одна идея, четыре реализации. Начало: дефолтный промпт сводки дословно.
    Главное: Claude Code (967K, /autocompact, что переживает), API threshold (usage.iterations, content:
    null), on-demand (подпись, два тихих промаха), OpenAI (непрозрачный item). Рис.: sequence on-demand.
    Выбор в конце.
11. `compaction-failures` — Когда сводка теряет главное. Начало: #92098 дословно. Главное: запрет
    жил в слое разговора; #84187 (agent_listing_delta, 24:25) и как проверить свои JSONL; OpenAI
    self-injection (27 сводок). Рис.: flowchart петли. Защиты.
12. `offload` — Файлы вместо окна. Начало: заметки Claude в Pokémon «For the last 1,234 steps».
    Главное: just-in-time vs предзагрузка, tool search 77K→8,7K, todo-рецитация Manus, харнесс
    для долгих агентов, memory tool как компонент (→ гл. 11), Ralph Wiggum.
13. `isolate` — Сабагенты. Начало: 6 100 прочитано → 420 вернулось. Главное: +90,2% и 15×,
    Cognition против, SWE-QA 2026 (41,8% сбоев на передаче). Рис.: sequence.
14. `million` — Миллион токенов. Начало: Claude Code компактит на ~967K, а NoLiMa падает на 32K.
    Главное: плоская цена Anthropic, 272K OpenAI, 200K Gemini; спор «40–60%» против «бери весь
    миллион»; рекомендация. Рис.: line стоимости запроса.

Дальше: самопроверка (10), чеклист (12), источники (≤45).

## Тесты по плану
- Анкета: разделы не идут «что/зачем/как/итог». Порядок: состав → порча → диагноз → рамки → деньги
  (три раздела) → место (чистка, компакция, её сбои, вынос, изоляция) → спор о миллионе.
- Первые предложения: открываются числом, цитатой, JSON-ответом, инцидентом, а не определением.
- Где провал: разделы 11 и 3 целиком про то, что ломается; ещё полевые выноски в 2, 5, 8, 14.
- Спорные места: 1M против частой компакции; примеры в промпте; сабагенты против семантического поиска.
