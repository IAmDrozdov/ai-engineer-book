# Глава 12. Deep agents — план

Шапка: Systima (июль 2026) замерила, что Claude Code отправляет 32,8 тыс. токенов до вопроса, OpenCode 6,9 тыс., Pi — меньше тысячи. Разница и есть харнесс.

## Разделы

1. `overhead` «Что харнесс отправляет вместо тебя». Начало: разбивка 32,8 тыс. (6,5 промпт / 24 схемы 27 тулов / 1,9 напоминания) против OpenCode. Главное: харнесс = всё вокруг модели (глоссарий Claude Code, «Agent = Model + Harness»). Подраздел: три окна в устройство Claude Code — документация и Agent SDK, утечка source map 2.1.88 (флаговые KAIROS/autoDream — не фичи), постмортем 23 апреля (харнесс-баги выглядят как «модель поглупела»).
2. `loop` «Цикл на уровне сообщений». Начало: пять типов сообщений Agent SDK и код `query`. Главное: ход, лимиты `max_turns`/`max_budget_usd`, параллельные read-only тулы. Codex: порядок элементов запроса, статeless без `previous_response_id`, причины промаха кеша. Cursor: харнесс под модель (−30% без reasoning traces, «preserve tokens» → отказы, GPT-5.6 Sol «runaway spirals»).
3. `pillars` «Четыре столпа Чейза и ревизия 2026 года». Начало: цитата «It's basically a no-op». Главное: планировщик отступил (Claude Code 2.1.233, deepagents 0.7, Pi никогда); что его заменило (plan mode, `/goal`, план-файлы, feature list). Спор о «подробном промпте»: Chase vs OpenAI «map, not manual» + полевой отчёт fleet. Что осталось: сабагенты, файлы, скиллы, компакция, проверка.
4. `subagents` «Сабагент — способ выбросить контекст». Начало: 6 100 токенов прочитано, 420 вернулось. Главное: что пересекает границу, фронтматтер, лимиты (глубина 3, 20 параллельно), Explore наследует модель, скан вывода сабагента. Форк (2.1.232). Лестница: форк → сабагент → команда → workflow (где живёт план). Команды молча формируются, workflow детерминированный JS.
5. `files` «Файлы вместо контекста». Начало: Cursor −46,9% токенов на MCP-прогонах за счёт папок с описаниями. Главное: пять ходов dynamic context discovery, восстановимое сжатие Manus, Managed Agents «сессия — не окно», бюджет листинга скиллов (1% окна) и полевой отчёт о пропадающих скиллах.
6. `compaction` «Когда окно кончается». Начало: порог ~967K и настройки. Главное: что переживает компакцию, circuit breaker при thrashing, Summary instructions / PreCompact; таблица трёх реализаций (Claude Code, Codex encrypted item, Pi session tree); context anxiety и сбросы контекста. Механика — глава 2.
7. `permissions` «Кто нажимает „да“». Начало: 93% одобрений. Главное: auto mode (уровни, двухстадийный классификатор, слепота к рассуждениям), FPR/FNR, «17% — честное число»; Cursor Auto-review и Codex auto_review сошлись к тому же; песочница под всем этим; хуки; полномочия между агентами. Подробно — глава 16.
8. `long-running` «Агент на много окон». Начало: bash-цикл Карлини и компилятор за $20 000. Главное: два разных Ральфа (внешний цикл vs Stop-хук), инициализатор + progress + feature_list.json, planner/generator/evaluator и «каждый компонент кодирует допущение», рои Cursor (20 агентов = 2–3). Провалы в центре.
9. `openclaw` «OpenClaw: харнесс, который живёт в мессенджере». Начало: heartbeat раз в 30 минут и NO_REPLY. Главное: хронология переименований, Gateway и WS-протокол, сборка хода из файлов воркспейса (HEARTBEAT.md больше не читается), уход от Pi agent core, ClawHub и ToxicSkills, CVE-2026-25253 по шагам, 722 advisories и тема «путаница полномочий», политика Anthropic.
10. `evidence` «Сколько процентов даёт харнесс». Начало: TB 4.0, Claude Code + Opus 5 от 34,85 до 51,82 только за счёт effort. Главное: LangChain +13,7 п. при той же модели; Transluce (таймауты); шум инфраструктуры 6 п.; aistack — решает одинаково, стоит по-разному; SWE-bench Verified сломан. Вердикт: харнесс надёжно меняет цену, долю решённых — через проверку и «не дать закончить».
11. `build` «Свой deep agent за вечер». Начало: Торстен Болл, <400 строк, три тула. Таблица открытых харнессов с выбором. Код: минимальный агент на Python (цикл, файлы вместо длинного вывода, сабагент, шлюз разрешений, проверка перед завершением), проверен на заглушке. Шаги в Claude Code на вечер.

Затем selfcheck (10 вопросов), checklist (12 пунктов), sources.

## Проверки плана (§3)

- Анкета: разделы не идут «что → зачем → как → плюсы/минусы». Раздел 3 построен как проверка утверждения (четыре столпа), 8 — начинается со сбоев и дорогих экспериментов, 10 — с проверки расхожего «харнесс важнее модели», 9 — с механизма (heartbeat), потом история, потом взлом.
