# План главы 03 «Проектирование инструментов агента»

Вводка: два MCP-сервера для одного приложения списка дел, одна модель, 40 запросов, у обоих 90%,
у одного в 4,98 раза больше входных токенов (JohnnyZhang483, HN, 2026-06-05).

## Разделы

1. `two-servers` «Куда ушли два с половиной миллиона токенов».
   Начало: таблица MCP-A против MCP-B. Главное: разница в трёх решениях (число тулов 47→14,
   поиск без `project_id`, сырой JSON из `create_task`), и у лучшего сервера описания втрое длиннее.
   Затем что модель получает на самом деле: шаблон системного промпта для тулов (Define tools),
   определения стоят до твоего системного промпта, 286 токенов оверхеда на Opus 5.5. ACI из
   «Building effective agents» (больше времени на тулы, чем на промпт), «контракт с
   недетерминированным агентом» (2025-09). Граница с главами 1 и 5.
   Рис.: hbar отношений MCP-B к MCP-A.

2. `workflow-tools` «Инструмент под задачу, а не под эндпоинт».
   Начало: 92% из 116 официальных серверов — обёртки над API, медиана 19% операций. Главное:
   каждый промежуточный результат обёртки идёт через контекст; `schedule_event`,
   `get_customer_context`, `search_logs`; `action`-параметр против god tool (разрешение из gaps #11).
   Рис.: sequenceDiagram три вызова через модель против одного.

3. `descriptions` «Описание читают на каждом ходу».
   Начало: Claude дописывал «2025» к каждому поисковому запросу, чинили описанием. Главное:
   что писать (Define tools, get_stock_price), настоящий пример — bash-тул SWE-bench; имена
   (MCP 2026-07-28, префиксы, `mcp__server__tool`, 2048 символов в Claude Code); замер «запахов»:
   97,1%, но полное дополнение даёт +5,85 п.п. и +67,46% шагов — больше текста не всегда лучше.
   Описания врут: 9,93% пар. Рис.: hbar качества экосистемы MCP.

4. `parameters` «Параметры, в которых трудно ошибиться».
   Начало: относительные пути в SWE-bench-агенте. Главное: poka-yoke, enum вместо двух булевых,
   не просить модель заполнять известное; форматы, которые тяжело писать (дифф, код в JSON) и
   custom tools OpenAI; strict с его бюджетами и дырами (нет minimum/maxLength), принудительный
   `tool_choice` отменён на Opus 5.5 и др.; `input_examples` и спор о примерах.
   Рис.: versus «что гарантирует strict / что остаётся серверу».

5. `responses` «Что вернуть модели».
   Начало: ответ поиска MCP-B без `project_id`. Главное: «что понадобится агенту дальше»;
   три вида идентификаторов (разрешение gaps #10); `response_format` 206 против 72 токенов;
   формат ответа; `structuredContent`; хэндлы состояния MCP 2026-07-28.
   Рис.: flowchart concise/detailed с последующим вызовом.

6. `truncation` «Усечение, которое не врёт».
   Начало: сервер нашёл 5 из 8 платежей и недосчитал $42 274 молча (Stainless). Главное:
   итог + образец + агрегат + точные следующие вызовы (пример Anthropic); лимиты Claude Code
   (10k, 25k, `maxResultSizeChars`, сохранение на диск); курсоры как аргументы.
   Рис.: рукописный SVG — анатомия усечённого ответа.

7. `errors` «Ошибка — тоже инструкция».
   Начало: две ошибки Asana (бесполезная и полезная). Главное: два канала ошибок MCP, с
   2025-11-25 ошибки валидации — ошибки выполнения; ретраи Claude 2–3 раза; различать типы
   ошибок; отказ политики как tool_result (auto mode, 3/20). Рис.: flowchart маршрутов ошибок.

8. `cost` «Сколько стоит каждый инструмент».
   Начало: пять серверов, 58 тулов, ~55 тыс. токенов до первого сообщения. Главное: цена в
   покое (GitHub 64,6k→30,3k, Playwright, Chrome DevTools против README на 225 токенов);
   нет одного «N тулов» — таблица порогов с условиями; замер IBM; кеш: правка `tools`
   сбрасывает весь кеш, детерминированный порядок в MCP 2026-07-28.
   Рис.: hbar токенов в покое; hbar IBM (2 ряда); flowchart что ломает кеш.

9. `tool-search` «Инструменты, которых модель пока не видит».
   Начало: JSON-запрос с `defer_loading`. Главное: механика у Anthropic (tool_reference,
   префикс не трогается, лимиты, GA с 2026-02-17), у OpenAI иначе (имя и описание видны,
   откладывается схема; неймспейсы); Claude Code: по умолчанию включено, `ENABLE_TOOL_SEARCH`,
   прокси; правки набора на лету (`tool_addition`); критика «лишний оверхед».
   Рис.: sequenceDiagram поиска; versus Anthropic/OpenAI.

10. `code-mode` «Код вместо вызовов».
    Начало: аргумент Cloudflare про Шекспира и мандаринский. Главное: code execution with MCP
    (150 000→2 000), PTC в текущем виде (`code_execution_20260120`, `allowed_callers`, `caller`),
    ограничения; серверный Code Mode Cloudflare; проверка цифр: 99,2% на шаге против ~50% счёта;
    отказ посередине скрипта; побег из песочницы workerd.
    Рис.: sequenceDiagram PTC; hbar «что измеряет процент».

11. `bash-cli` «Bash, CLI или MCP».
    Начало: 49% SWE-bench с двумя тулами (январь 2025). Главное: Pi (4 тула, <1000 токенов),
    замер Цехнера (120 прогонов, оба 100%), Ронахер про CLI и ubertool, голоса с HN 2025 и
    2026; где MCP нужен (хосты без шелла, агрегация, авторизация). Рис.: flowchart выбора.

12. `side-effects` «Побочные эффекты: подтверждение, повтор, параллельность».
    Начало: три источника повторов одного вызова. Главное: ключ идемпотентности (семантика
    Stripe, пометка «собрано из»), аннотации MCP как подсказки, механизмы подтверждения
    (`requiresUserInteraction`, `needs_approval`, Managed Agents `auto`), параллельные вызовы.
    Рис.: sequenceDiagram повтора с ключом.

13. `iterate` «Улучшать описания циклом».
    Начало: агент-тестировщик Anthropic, −40% времени задачи. Главное: цикл прототип → задачи →
    прогон → чтение транскриптов → Claude Code переписывает → отложенная выборка; pass^k;
    рецепт на вечер (ol.steps). Методика evals — глава 17.

Потом: самопроверка (10 вопросов), чеклист (12 пунктов), источники (~42).

## Тесты плана (§3)

- Анкета: порядок не «что → зачем → как → плюсы → итог». Разделы открываются замером,
  инцидентом, JSON-запросом или цитатой; раздел 3 заканчивается опровержением «больше
  описания — лучше», раздел 10 — проверкой рекламной цифры, раздел 11 — спором с выбором.
- Первые предложения разделов: «Два MCP-сервера…», «92% из 116…», «Когда Anthropic
  запустила веб-поиск…», «Агент для SWE-bench путался…», «Поиск MCP-B возвращал…»,
  «Сервер нашёл пять платежей из восьми…», «Вот ошибка, которую вернул…», «Пять серверов…»,
  «Запрос выглядит так…», «Cloudflare объясняла…», «В январе 2025…», «Модель повторяет…»,
  «Агент-тестировщик…» — это не конспект главы, а набор отдельных фактов.
- Где провал: в разделах 3, 6, 10, 11, 12 (замеры с регрессиями, молчаливое усечение,
  побег из песочницы, отказы CLI, двойные списания).
